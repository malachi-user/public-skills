# מפנייה למעקב ב־4 דקות

מצגת Reveal.js בעברית לסדנה בת 12 דקות לבעלי עסקים קטנים.

## הפעלה

אפשר לפתוח את `index.html` ישירות, או להגיש את התיקייה בשרת סטטי:

```bash
python3 -m http.server 4173
```

## ניווט

- חצים או רווח: קדימה/אחורה
- קליק שמאלי על אזור לא אינטראקטיבי: קדימה
- קליק ימני: אחורה
- `F`: מסך מלא
- `B`: מסך שחור
- `T`: החלפת ערכת צבעים

Reveal.js והפונטים מאוגדים מקומית, ולכן המצגת אינה תלויה ב־CDN. הפריסה כוללת כותרות אבטחה, מנגנוני נגישות ופרטיות, ואינה כוללת כלי מעקב.
